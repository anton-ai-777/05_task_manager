# 📋 Task Manager

Консольный менеджер задач на Python.

## 🚀 Возможности

- 📋 Просмотр списка задач
- ➕ Добавление новой задачи
- ❌ Удаление задачи
- ✅ Отметка задачи как выполненной

## 🛠 Используемые технологии

- Python 3.13

## 📚 Изученные темы

- Списки (`list`)
- `append()`
- `pop()`
- `enumerate()`
- `len()`
- Условные конструкции (`if`, `elif`, `else`)
- Цикл `for`
- Пользовательский ввод (`input()`)

## ▶️ Запуск

```bash
python main.py
